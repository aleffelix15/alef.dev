# Alef.dev — Portfólio Pessoal

> Desenvolvedor Fullstack & Entusiasta de IA. Construindo produtos digitais, experiências interativas e aplicações modernas.

## 🚀 Tecnologias

- **Frontend:** React, TypeScript, Tailwind CSS, Framer Motion, Lucide Icons
- **Backend & APIs:** Java, Spring Boot, Spring Security, Python, RESTful APIs
- **Banco de Dados:** Supabase, PostgreSQL
- **Build & Ferramentas:** Vite, Git, GitHub

## 🌟 Projetos em Destaque

- **Banking System API** — API Backend para operações bancárias digitais e detecção de fraudes
- **Jarvis** — Assistente virtual e automação inteligente com integração de modelos de IA

## 📦 Como rodar localmente

```bash
# Instalar dependências
npm install

# Rodar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
